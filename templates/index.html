What This Project Is & How I Engineered It From Scratch

Welcome to Project 04: The Production LLM Twin System. Instead of building a toy ChatGPT wrapper in a single Jupyter notebook, I engineered a complete 3-Pipeline FTI (Feature → Training → Inference) Production LLMOps System modeled after Decoding ML's LLM Twin Course (Paul Iusztin) and Umar Jamil's LLaMA & Mistral Architectures from Scratch.

Pipeline 1: Feature Pipeline MongoDB + Qdrant

Multi-source ETL crawlers ingest my GitHub repositories, Medium deep-dives, and LinkedIn posts, validate them via Pydantic ODM schemas into a MongoDB Document Warehouse, and stream overlapping embedded chunks into a Qdrant Vector Database.

→ Explore Warehouse & Live Ingestion
Pipeline 2: Training Pipeline CometML + PEFT LoRA

Distills Qdrant chunks into (instruction, input, output) triplets versioned in CometML & DagsHub MLflow. Fine-tunes google/flan-t5-small with PEFT LoRA (r=8, α=16) updating only 0.4451% of parameters while boosting Style Alignment by +43.82%.

→ Inspect LoRA Metrics & HF Registry
Pipeline 3: Inference & LLMOps Multi-Agent + Opik

Orchestrates 4 specialized agents (RouterAgent → ResearcherAgent with $k=3$ Query Expansion, Self-Query & RRF → TwinWriterAgent → SafetyCriticAgent), paired with an A/B Router, Comet Opik Traces, and a DPO Retraining Queue.

→ Launch Multi-Agent Twin Studio
Step-by-Step: How I Developed This System 12 Engineering Milestones
Phase Module Mathematical & Architectural Implementation
Phase 1 llama_mistral_from_scratch.py Implemented RMSNorm ($\text{RMS}(x)=\sqrt{\frac{1}{d}\sum x_i^2+\epsilon}$), complex-plane RoPE ($e^{im\theta_j}$), SwiGLU ($\text{SiLU}(xW_G)\odot xW_U$), and Grouped-Query Attention (GQA) with Mistral Sliding Window Attention ($W=32$).
Phase 2 feature_pipeline.py Built Pydantic ODM models (RepositoryDocument, ArticleDocument, PostDocument), dual-mode MongoDB storage, and 256-D semantic + n-gram vector indexing into Qdrant.
Phase 3 training_pipeline.py Distilled 24 training + 6 validation instruction pairs, fine-tuned PEFT LoRA adapter (`ROUGE-L: 0.2692 -> 0.5666`, `Style: 0.3317 -> 0.7699`), logged to CometML & DagsHub, and pushed weights to Hugging Face Hub (29Oms/mlops-project-4-llm-twin-adapter).
Phase 4 inference_pipeline.py Built 4-stage Advanced RAG ($k=3$ Query Expansion + Self-Query Metadata Filters + Qdrant/BM25 RRF + Reranker), SafetyCritic prompt-injection & PII redaction guardrails, A/B testing duel mode, and DPO feedback loop.
